# Linear

Retro tickets: process/agent improvements found during work.

## Destination
- Project: `No Drama Club`. Label: `retro`.
- Create the project or label if missing.

## Ticket format
- **Title**: imperative, specific.
- **Problem**: what went wrong or is unclear.
- **Evidence**: plan slug, step/cycle, `file:line` or memory quote.
- **Affected file**: agent/skill/rule path.
- **Suggested change**: concrete edit.

## Dedupe
1. Search open issues with label `retro` first.
2. If one matches, comment with the new evidence. Do not create a new ticket.
3. Otherwise create a new ticket.
